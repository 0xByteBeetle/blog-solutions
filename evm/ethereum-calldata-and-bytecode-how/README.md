# Ethereum calldata and bytecode

Code for [How the EVM Knows Which Function to Call](https://andreyobruchkov1996.substack.com/p/ethereum-calldata-and-bytecode-how).

`src/MiniExample.sol` is the article's unchanged contract. The focused tests and Foundry configuration are supplemental. No npm packages, OpenZeppelin, forge-std, wallet or network endpoint are required.

Tested with Foundry 1.4.4; the config pins Solidity 0.8.30. From this folder:

```sh
forge test
cast calldata 'set(uint256)' 69420
forge inspect MiniExample bytecode
```

Tests check the selector/argument bytes, storage update, and rejection of unknown selectors and missing arguments. Compiler metadata/options can change generated bytecode; the build is not a claim of byte-for-byte reproduction of the article's historical output.

## Foundry project

The runnable project is here: [foundry.toml](foundry.toml), [src/](src/) and [test/](test/). Run `forge build` and `forge test` from this article folder. No repository-root setup is required.
